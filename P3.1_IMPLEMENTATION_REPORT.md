## 1. Apa yang diperbaiki

Audit P3 menemukan satu rantai destruktif end-to-end (CRITICAL-1): `--session
<id>` pada id yang sudah berhistori memulai buffer runtime kosong, lalu
`persistCurrent` menangkap `RefusedHistoryRewriteError` dan meng-`shrinkThreadHistory`
buffer baru — **histori kanonik lama diganti**, tanpa arsip, tanpa peringatan
(probe CLI nyata: 6 baris → 2 baris).

P3.1 menutup rantai itu di dua titik dan menambahkan kelas kegagalan eksplisit:

1. **Attach implisit ditolak** (`SessionAttachRefusedError`) — sebelum provider
   dibelanjakan, bukan setelah kerja user dibuang.
2. **Publikasi kanonik hanya boleh append-extension.** Buffer yang divergen /
   menyusut / ter-fold / diurut-ulang / diganti = `DIVERGED` → **DITOLAK**;
   kanonik tidak disentuh, tidak ada shrink, tidak ada retry destruktif.
3. **Refusal tidak pernah jadi exit 0** dan **selalu meninggalkan bukti durable**
   (event presentasi `diagnostic.raised`, kategori `RECONCILIATION_CONFLICT`)
   lewat jalur yang sudah ada — tanpa penyimpanan baru.

## 3. Kontrak yang sekarang ditegakkan (dengan bukti)

| Input publikasi | Kelas | Perilaku | Bukti |
| --- | --- | --- | --- |
| Kanonik adalah prefix sejati buffer | `APPEND` | dipublikasikan sebagai baris baru | A, D, P2 |
| Panjang sama + prefix identik | `IDENTICAL` | idempoten (tanpa baris/turn/identitas baru) | E |
| Penghapusan / urutan terbalik / isi diganti | `DIVERGED` | **DITOLAK**, kanonik utuh (fingerprint identik) | B, C |
| Buffer ter-fold kompaksi (menyusut, non-prefix) | `DIVERGED` | **DITOLAK** di jalur persist nyata | C2, P1 |
| Kanonik tumbuh dari penulis lain | `DIVERGED` | **DITOLAK**, baris penulis lain tidak ditimpa | P4 |
| `--session <id>` pada id berhistori | — | `SESSION_ATTACH_REFUSED`, exit 1, **sebelum** panggilan provider | G, P3 |
| Baris sesi tanpa histori | — | tetap boleh dipakai ulang (tak ada yang bisa ditulis ulang) | G2 |
| Epoch sudah pindah (take-over) | — | **STALE WRITER**, bukan konflik rekonsiliasi (fence menang) | P5 |
| Klasifikasi baca-saja vs keputusan `saveSession` | — | setara (satu implementasi pembanding) | F |
| Refusal | — | bukti durable `diagnostic.raised` / `RECONCILIATION_CONFLICT` | P1 |

Semantik UNKNOWN dijaga: klasifikasi yang **tidak dapat membaca** kanonik
(DB tak terbaca) mengembalikan `DIVERGED` → fail-closed **ditolak**, bukan
"tidak terbukti, jadi izinkan".
