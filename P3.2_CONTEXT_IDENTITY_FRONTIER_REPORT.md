## 5. Context Identity Contract

`ContextIdentity = { sessionId, threadId, baseSeq, anchorEventId }`
(`src/session/context-identity.ts:68-78`). Yang masuk: hanya 4-tuple.
Yang ditolak: `run_id`, model, provider, prompt fingerprint, RAG hit, buffer runtime.
`anchorEventId` = `ctxev_<32hex>` = SHA-256 atas `(session, thread, seq, ISI kanonis baris
durable)` — namespace `p32-context-anchor-v1:`. Thread default `"main"` (seam P3.9).
Derivasi fail-closed: input invalid → throw, tak pernah tebak. Objek di-freeze.

## 6. Frontier Contract

`ContextFrontier` = identity + `headSeq`, `lastSeenSeq`, `lastSeenEventId`, `revision`,
`historyCommit` (`context-identity.ts:91-104`). Definisi yang dikunci (satu istilah, satu arti):
`baseSeq` = seq pertama yang dicakup view; `headSeq` = seq kanonis terakhir yang dicakup;
`anchorEventId` = jangkar konten pada head; `lastSeen*` = frontier kanonis saat view dibangun
(pada selector penuh = head; selector parsial P3.3 boleh beda — dibedakan eksplisit);
`revision` = ruang-sekuens kanonis = cacah durable `context.compacted` (NaN bila kompaksi
tanpa adapter = seam P3.5, bukan angka tebakan); `historyCommit` = `ctxhist_<32hex>` =
komitmen atas **seluruh** isi cakupan view (menutup lubang F-05: endpoint sama, tengah beda).
`projection frontier` dan `runtime unpublished frontier` didefinisikan sebagai istilah
untuk P3.4/P3.5 — buffer runtime tidak masuk frontier kanonis (prinsip: runtime buffer ≠ truth).
Perbandingan `compareContextFrontier` → EQUAL / A_AHEAD / B_AHEAD / DIVERGED / UNKNOWN —
tanpa timestamp, `Date.now`, identitas objek, index array, posisi prompt, atau run_id.

## 7. Identity != Sequence

`event_id != seq` ditegakkan secara konstruksi (seq hanya satu komponen hash bersama
session+thread+isi) dan oleh 7 test: A (seq sama isi beda), A2 (rewrite N→N: anchor head sama,
commit beda → DIVERGED), B (seq sama session beda/fork), B2 (posisi sama cakupan beda ≠ EQUAL),
C (replay JSON round-trip stabil), D (append tak menulis ulang identity lama, objek frozen),
E (rekonstruksi dari durable murni). Mutasi B (anchor = seq saja) menggagalkan tepat test
A, B, dan isolasi thread (§12).

## 8. Reconstruction Contract

`deriveFrontierFromDurable({ sessionId, threadId?, rows, revision })` hanya memakai baris
durable: diurutkan stabil per seq, seq duplikat/non-monotonik → throw (fail-closed), rows
kosong → null (pemanggil nilai UNKNOWN, bukan error). Menjamin: identity sama, frontier sama
(termasuk `historyCommit`), urutan sama, referensi event kanonis per-baris sama — tanpa
ContextStore runtime, memori proses, invocasi model, atau state tersembunyi. Gate diuji oleh
test restart ("durable → hancurkan runtime → rekonstruksi", JSON round-trip) yang gagal pada
mutasi A2/D (§12).

## 9. Staleness / Divergence / UNKNOWN

`assessContextFreshness(context, canonical)`: FRESH (head+anchor sama; base beda = perbedaan
selector, bukan basi; base sama + commit beda = DIVERGED), STALE (`100→103`: kanonis append;
pemanggil wajib rebuild — context tak pernah otomatis menjadi kanonis), DIVERGED (seq sama
anchor beda; revisi kanonis naik = kompaksi di bawah context), UNKNOWN (sisi null/invalid,
session/thread asing, revisi masa depan, head melampaui kanonis). UNKNOWN first-class:
6 test khusus; null ≠ error. Aturan revisi menutup bahaya salah-baca pasca-kompaksi
(head menyusut 100→39 terbaca A_AHEAD bila tanpa revisi — kini DIVERGED).
